# dsh-web-clipper

**状态：规划中 · Status: planned.** 尚无可用版本。

## 要解决什么

把网页内容交给 dsh，现在只能：抓整页 HTML（噪音极大）或手动复制粘贴（丢格式、丢链接）。

## 计划做什么

把**一个网址或当前浏览器页面**转成**干净 Markdown** 落到工作区文件里，然后由 agent 正常读取：

- 正文提取（去广告/导航/侧栏），保留标题层级、代码块、表格、图片链接
- 附上**来源 URL 与抓取时间**，方便日后溯源
- 批量：一次剪藏多篇到同一目录，形成可检索的小资料库

## 不做什么

- **不**做阅读器 UI，**不**做全文检索——剪藏完就是工作区里的普通 Markdown，交给 dsh 自己的工具读
- **不**绕过登录墙、付费墙或 robots 限制

## 与同类项目的分工

`browser` 类插件（如 BrowserSkill）侧重**让 agent 操作浏览器**；本项目只做**单向、可留档的内容落地**，更轻、更适合"收集资料"这个高频动作。
